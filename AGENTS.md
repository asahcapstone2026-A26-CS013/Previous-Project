# KM. Karya Lestari

Aplikasi website antrean digital dan pemesanan ikan segar.

- Frontend: React + Vite + Tailwind CSS (`src/`)
- Backend: Supabase Edge Function (Hono) di `supabase/functions/server/`
- Semua endpoint berada di bawah `/api/v1/...`
- Gaya kode: fungsi bernama, tanpa arrow function berlebihan, modul kecil satu tanggung jawab
